During this feature cycle, I split AI usage clearly across tools: I used ChatGPT to draft the user stories and the mini-ADR, and then used GitHub Copilot for the rest of the workflow (planning loops, implementation edits, testing, and verification). In practice, Copilot was used for implementation sequencing, targeted code edits, terminal-driven pytest runs, and browser-based manual checks. I used it first as a planning partner to break the task-comments feature into short loops (model/schema, storage, endpoint, tests, then frontend wiring). That sequencing reduced context switching and made each layer easier to verify before moving on.

The strongest AI contribution was speed in connecting backend and frontend contracts. Once the comment endpoint shape was settled, AI assistance helped quickly propagate the same assumptions across Pydantic validation, storage persistence, API response handling, and UI refresh behavior. In practice, this meant fewer mismatches between what the frontend expected and what the backend returned. The test-writing assistance was also useful: it generated small, readable FastAPI TestClient tests that aligned with the project’s existing style and fixtures.

One moment AI slowed me down was command execution context. A generated command initially failed in PowerShell because of invocation syntax around the Python executable path. The fix was simple, but it cost extra cycles: I had to correct the command format and rerun tests. This was a useful reminder that AI-generated shell commands are often close, but environment details still need human verification.

The most important place where review changed the result was test completeness. At first, the test suite already covered most comment scenarios, but a close review of the requirement list showed one explicit gap: empty-string comments were not tested separately from whitespace-only comments. I added that focused test and strengthened another assertion to verify exact comment list contents, not just count. That review step improved confidence in the behavior contract and made the evidence stronger for regressions.

Overall, AI tools were most effective when used for draft generation, cross-file consistency, and repetitive scaffolding, while human review remained essential for requirement coverage, environment-specific command correctness, and final quality control.
